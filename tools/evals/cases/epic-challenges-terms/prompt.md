Here's the PRD for a loyalty programme, turn it into an epic: "Members earn points on every order and spend them at checkout. A member can merge their points with another member's account." The hub's `docs/GLOSSARY.md` currently says:

```markdown
## Checkout

### Customer
A person or organisation that places orders.
_Avoid_: account, client, member
```

Load any skill that applies before you answer, as a real session would. Don't run any commands or edit files yet: tell me exactly what you will do, step by step, with any commands you would use, and the questions you would ask me first.
